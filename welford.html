Welford's Recurrence and Sampling Statistics

Exercise 1: recurrence formulas for the sum of squares and the variance. Exercise 2: sampling mean and variance of m hackers attacking n systems.

Exercise 1. Welford's recurrence formulas

Notation

Let x1, x2, … be a sequence of numbers. After n values the sample mean, the sum of squares and the sample variance are

xn = (x1 + … + xn) / n,    SSn = Σi=1..n (xi − xn)²,    s²n = SSn / (n − 1).

The aim is to update these three quantities when a new value xn arrives, without going back over the old values. We use the short notation δn = xn − xn−1, the difference between the new value and the old mean.

Step 1: the mean (Knuth)

From nxn = (n − 1)xn−1 + xn we obtain

xn = xn−1 + (xn − xn−1) / n = xn−1 + δn / n.

Two consequences are used below: xn = xn−1 + δn and xn − xn = δn − δn/n = δn(n − 1)/n.

Step 2: the sum of squares

We use the identity SSn = Σ xi² − nxn². Taking the difference of two consecutive steps gives

SSn − SSn−1 = xn² − nxn² + (n − 1)xn−1².

Write x for xn−1 and δ for δn. Then xn = x + δ and xn = x + δ/n, so

xn² = x² + 2xδ + δ²
nxn² = nx² + 2xδ + δ²/n

Substituting these two lines, the terms with x cancel:

SSn − SSn−1 = δ² − δ²/n = δ²(n − 1)/n = δn · (xn − xn),

where the last equality uses xn − xn = δ(n − 1)/n from Step 1. Therefore

SSn = SSn−1 + (xn − xn−1)(xn − xn),   with SS1 = 0.

Step 3: the variance

Since s²n = SSn/(n − 1), we can divide the previous result and write the recurrence directly for the variance. Using SSn−1 = (n − 2)s²n−1 and SSn − SSn−1 = δ²(n − 1)/n,

s²n = ((n − 2)/(n − 1)) s²n−1 + δn² / n,   for n ≥ 2.

In practice it is simpler to keep SS and divide at the end: s²n = SSn/(n − 1) is the unbiased sample variance, and SSn/n is the version that divides by n.

Code

The core of the update is the three lines in bold. The rest is initialisation and the final division.

def welford(xs):
    n = mean = ss = 0
    for x in xs:
        n += 1
        d = x - mean            # delta_n = x_n - mean_(n-1)
        mean += d / n           # Knuth: new mean
        ss += d * (x - mean)    # (x_n - old mean)(x_n - new mean)
    return mean, ss / (n - 1)   # sample mean, sample variance

Only n, the mean and SS are stored, so a new value can be added at any time and the old values can be discarded. The formula also avoids the subtraction of two large, almost equal numbers that appears in Σx² − nx², which makes it numerically more stable. I checked the function against the direct formulas on random data and the results agree to machine precision.

Exercise 2. Sampling mean and variance

Setting. Each of the m hackers attacks n systems and gets one score per system, an integer from 0 to 10. The scores are independent and follow a fixed distribution with mean μ and variance σ². For every hacker Welford's recurrence gives the sampling mean x and the sampling variance s² of the n scores (dividing by n − 1). The simulation then averages these m values over the hackers and compares them with μ and σ².

Default distribution. Binomial(10, 0.3), which gives μ = 3 and σ² = 2.1. It is not symmetric, so it is a fair test for the variance.

Conclusions

  
    
    
  • Average of the sampling means. It is very close to μ for every n, even for n = 5 (2.994 against 3). The sample mean is an unbiased estimator: E[x] = μ, so the errors of individual hackers cancel on average.
    • 
    
  • Average of the sampling variances. It is also close to σ² = 2.1 for every n, so s² with the divisor n − 1 is unbiased: E[s²] = σ². The column “Average of SS/n” shows why n − 1 is needed. If SS is divided by n, the average is (n − 1)/n · σ², which is clearly too small for small n (1.68 for n = 5) and only becomes correct when n is large.
    • 
    
  • Why this is useful in inferential statistics. In practice we observe only one sample and do not know μ and σ². The experiment shows that estimating them with x and s² is correct on average, so the estimates can be used for confidence intervals and tests. Welford's recurrence computes them in one pass, which matters when data arrive as a stream or are too many to store.
    • 
    
  • Effect of n on the sampling mean. Var(x) = σ²/n, so its standard deviation is σ/√n. In the table it goes from 0.65 (n = 5) to 0.014 (n = 10,000), which is about √2000 ≈ 45 times smaller for an n that is 2000 times larger, and it agrees with the theoretical value. The sampling mean is therefore also consistent: with more systems each hacker's mean is closer to μ.
    • 
    
  • Effect of n on the sampling variance. Its variance is (μ4 − (n − 3)/(n − 1) · σ4)/n, where μ4 is the fourth central moment, so it also decreases like 1/n and the standard deviation like 1/√n (1.44 for n = 5, 0.029 for n = 10,000). The variance is harder to estimate than the mean: for the same n its standard deviation is about twice as large here (0.029 against 0.014).
    • 
    
  • Effect of the number of hackers m. The averages over the hackers are themselves means of m independent values, so their error is about (standard deviation of one hacker)/√m. For n = 10 this is 0.458/√5000 ≈ 0.006, which explains why the averages in the table agree with μ and σ² to two or three digits. A larger m makes the comparison sharper, but only a larger n makes each single hacker more reliable.
